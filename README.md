# Book Bingo Image Maker for @2026-book-bingo

I didn't even realize this project had a default readme.md until I uploaded this to github. Wild.

## How To Use

This was made for computers with mice because I am a dinosaur and do not think mobile first ever. 

* Hovering over a slot shows Emoji and Edit buttons.

* Click the Emoji and Edit buttons to add emojis or edit the book.

* Click added emojis to remove them. 

* Click a bingo slot anywhere else to cycle between three colors (white, green, and blue).

* Data is saved to localStorage (browser cache) only.

## Tech Notes

Built with React + Typescript + Vite and uses emoji-picker-react (https://github.com/ealush/emoji-picker-react)
